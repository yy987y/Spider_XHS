# 小红书帖子采集

## 工作流

1. 确认当前目录是 Spider_XHS 仓库，或让用户提供仓库路径。
2. 检查 `.env` 是否有 `COOKIES`，不要输出 Cookie 内容。
3. 检查账号 Excel 是否包含 `red_id` 列。
4. 一轮任务只处理一组完整搜索词和一组看板关键词。
5. 优先通过 `scripts/run_collection.py` 调用项目 CLI，不要重写采集逻辑。
6. 运行后汇报 Excel、JSONL、logs JSONL 路径，并说明是否出现候选上限、账号解析失败、接口失败或可能未抓全。

## 常用命令

```bash
python skills/xhs-note-collector/scripts/run_collection.py \
  --repo . \
  --users-excel ./users.xlsx \
  --task-name 艾薇岚大超炮北京 \
  --search-query "艾薇岚 大超炮 北京" \
  --keywords "艾薇岚,大超炮,北京" \
  --date-range recent_7_days \
  --mode both \
  --max-search-candidates 1000
```

## 何时读取 references

- 需要字段、sheet、JSONL 结构时，读取 `references/input-output.md`。
- 需要验收、smoke run 或排查失败时，读取 `references/verification.md`。
